# v0.4 UI (W5-5): charts, pictures, print/PDF, split window, detective — manual check script

Run `pnpm --filter tally-desktop dev:web` and open `http://localhost:5173/?template=invoices`
(WebMockClient emulates the chart ops, `chart_data`, `suggest_chart`, the print layout, page
PNGs and the detective queries), then repeat the starred steps in `pnpm tauri dev` against the
engine once W5-1 (charts) and W5-3 (print pipeline) have landed.
Automated: `tests/e2e/charts.spec.ts`, `tests/e2e/print.spec.ts` (browser flows; the mock records
ops in `window.__tally.client.recorded` and `printLayout` / `preparePrintJob` calls in
`recordedCalls`; live ECharts instances are at `window.__tallyCharts[id]`),
`packages/app/test/{toEcharts,objects,printPreview,detective,mockW5}.test.ts`,
`packages/grid/test/w55.test.ts`, and the Rust unit tests in
`apps/desktop/src-tauri/src/{print,images,windows}.rs`.
Screenshots: `docs/qa/screenshots/v04-*.png`, regenerated with
`pnpm --filter tally-desktop exec playwright test -c ../../tests/e2e/screenshots.v04.config.ts`.
★ = repeat against the engine (the mock derives series itself, formats nothing, and draws page
PNGs on a canvas without charts).

## Charts

| # | Step | Expected |
|---|---|---|
| 1 | Select A1:C7, toolbar **Chart** | A column chart appears right of the region (16 × 9 cm), selected with 8 handles; the Chart editor panel opens on the right (`v04-chart-grid.png`, `v04-chart-editor.png`). The mock derives the series from the wizard range (first row = names, first column = categories) ★ |
| 2 | Click a single cell inside the table, **Chart** | `suggest_chart` picks the whole region around the cursor ★ |
| 3 | Editor ▸ Type: Bar, Line, Area, Pie, XY, Bubble, Net, Stock | Each switch is one undo step ("Edit chart"); bar swaps the axes, pie draws one ring per series (Donut = hole 50 %, Exploded offsets the slices), Net uses the categories as spokes, Stock expects Low/High/Close (Open first for OHLC, Volume first for the volume variants) |
| 4 | Stacking None / Stacked / Percent on a column chart | Stacked bars; Percent normalises every category to 100 % |
| 5 | Titles: type a title and press ↩; Legend: Bottom | The title appears over the plot; the legend moves. Each field commits on blur/↩ (one op) |
| 6 | Data: click ⤓ next to a series' Values, drag A2:A7 on the sheet | The grid enters range-pick mode (the chart stays selected), the field shows `$Orders.$A$2:$A$7`, one `updateChart` is sent; Esc cancels a pick |
| 7 | Data: **+ Add series**, type `$Orders.$F$2:$F$15` as values; set "Series type" to Line and "Secondary axis" | A combo chart with a second Y axis on the right; Axes ▸ Secondary Y tab appears |
| 8 | Axes: Y min 0, max 100, major 20, number format `#,##0.0`, Logarithmic, Reverse, grids | Axis labels follow the format; log scale and reverse apply |
| 9 | Data labels: Value + Category, placement Above | Labels above each bar with the formatted value |
| 10 | Statistics: Trend line Linear with equation and R²; Error bars Standard deviation; Mean value line | A dashed trend line with its equation as end label; I-shaped error bars; a dotted mean line ★ (the mock computes least squares like `RSQ`) |
| 11 | Type a new value in a cell of a series range | The chart updates (`chartsChanged`); typing elsewhere does not refresh it ★ |
| 12 | Drag the chart by its body; drag the SE handle | One `moveResizeChart` per drag ("Move chart" / "Resize chart"); ⌘Z restores. Arrow keys nudge 1 mm (⇧: 10 mm) |
| 13 | Select the chart, press Delete; ⌘Z | The chart disappears and comes back; "Delete chart" in the panel does the same. Esc deselects |
| 14 | Double-click a chart / Format ▸ Chart ▸ Edit Chart… | Opens the editor for that chart; `chart.edit` without a selection shows a hint toast |
| 15 | ⌘C on a selected chart, click a cell, ⌘V | A copy is added at the active cell (`addChart`); the system clipboard holds a PNG of the chart ("Copy as image" too) |
| 16 | Scroll the chart off screen and back; insert 25 charts | Instances are disposed off screen and recreated (at most 20 live); charts scroll with the cells and are clipped at frozen panes (objects never sit in frozen panes) |
| 17 | View ▸ Theme: dark | Chart text, axes, grid lines and the background follow the theme |
