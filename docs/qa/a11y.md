# Accessibility: VoiceOver walkthrough and the ARIA mirror

Wave 5, §4 item 46 (W5-0b landed the mirror; W5-6E polishes dialogs and strings);
1.0 accessibility pass (keyboard-only dialogs, ARIA roles, axe in e2e).

What the canvas grid exposes (`packages/grid/src/aria.ts`, `AriaMirror`):

| Element | ARIA |
|---|---|
| Grid root (`.tally-grid`) | no role: it holds the canvases, the cell editor, the offscreen grid and the live region |
| Offscreen grid (`data-testid="aria-grid"`) | `role="grid"`, `aria-rowcount="1048576"`, `aria-colcount="16384"`, `aria-multiselectable="true"`, `aria-label="Sheet <name>"`; owns only the row below (ARIA: a grid owns rows, so the editor and the live region are its siblings) |
| Offscreen active cell | `role="row"` (`aria-rowindex`, 1-based) › `role="gridcell"` (`aria-rowindex`, `aria-colindex`, `aria-selected="true"`), text "B2: 42" / "B2: empty" / "C1: 6, formula =A1*B1" (`data-testid="aria-active-cell"`) |
| Cell editor (`textarea`) | `aria-label="Cell editor"`, `aria-activedescendant` → the active cell node; always focused while the grid has focus |
| Live region | `role="status"`, `aria-live="polite"`, `aria-atomic="true"` (`data-testid="aria-live"`); announces "address: value[, formula …][, selected A1 to C3 (3 rows, 3 columns)][, plus N more ranges]" on every selection change and when the active cell's value changes |
| Objects layer | `role="group"` "Objects"; each chart/picture `role="img"` with its title, `aria-selected` while selected |
| Dialogs (`Shell`, `W56Shell`, Save prompt, Keyboard shortcuts, Print Preview, About) | `role="dialog"` (Save prompt: `alertdialog`), `aria-modal="true"`, `aria-labelledby` → the title; focus starts inside; every Tab / Shift+Tab is handled by `trapTab` (`components/trapTab.ts`), wraps, and skips hidden controls, so buttons are reachable in WebKit too; Escape cancels; Enter in a field submits the default button; on close the focus returns to the opener (`useReturnFocus` in `components/dialogA11y.ts`; the grid when opened from the grid or a menu) |
| Composite widgets in dialogs | `arrowNav` (`components/dialogA11y.ts`): ←/→ (or ↑/↓) / Home / End inside a `tablist`, `radiogroup`, `listbox`, `menu` or `toolbar`; selection follows the focus for tabs, radios and single-select options; tabs use a roving `tabindex` |
| Function Wizard | search is a `combobox` (`aria-controls` / `aria-activedescendant`) over `role="listbox"` › `role="option"` (`aria-selected`) |
| Font pickers (`FontPickers.tsx`) | font name / size: `combobox` + pop-up `listbox`; the virtualised options carry `aria-setsize` / `aria-posinset`; section headers are hidden from AT; Typeface and Size lists in Format Cells are focusable `listbox`es with `aria-activedescendant` (↑/↓/Home/End) |
| Toolbars | the format bar and the "»" overflow panel are `role="toolbar"` with ←/→/Home/End; "»" has `aria-expanded` / `aria-controls`; opened from the keyboard it moves the focus into the panel and Esc returns to "»" |
| Menus (`Popover`) | `role="menu"` › `menuitem` / `menuitemcheckbox` (`aria-checked`), ↑/↓/Home/End; a command run from a menu returns the focus to the menu's opener |
| Sheet tabs | `role="tablist"` "Sheets" holding only the tabs (Add sheet sits outside); one tab stop (roving `tabindex`), ←/→/Home/End switch sheets |
| Sidebar "Editing" list | vertical `tablist` "Open documents" › `tab` (`aria-selected` = this window's document); ↑/↓/Home/End, Enter shows, Delete closes, ⇧F10 / menu key opens the row menu; the × is pointer-only (`aria-hidden`) |
| Print Preview | modal dialog; focus starts on Close; the page area is a focusable region (scroll with the arrow keys) |

Reported, not gated: axe's `color-contrast` (serious) is excluded from the failure set and
logged as a test annotation. It flags the grey secondary text (`--tally-gray-500` on the
status bar and in dialog notes, 4.4:1 and 3:1) and the accent-on-tint selected list rows
(3.4:1); changing them is a design-token decision for the owner.

Known gaps: VoiceOver cannot be scripted, so the walkthrough below stays manual. The
grid's mirror and live-region strings ("B2: empty", "selected … to …", "Cell editor") are
English only (the grid package has no `t()`); several older dialog labels in
`V3Dialogs.tsx` / `DataDialogs.tsx` are English literals too.

## VoiceOver script (macOS)

Run `pnpm tauri dev` (or `pnpm dev:web` and `http://localhost:5173/?template=invoices`),
turn VoiceOver on (⌘F5). VO = Control+Option.

| # | Step | Expected |
|---|---|---|
| 1 | VO+Right until the grid | "Sheet Invoices, grid, 1,048,576 rows, 16,384 columns" (the sheet name comes from the tab) |
| 2 | ↓, → | VoiceOver reads "B2: …" (the live region: address, then the displayed value; "empty" for an empty cell) |
| 3 | Move onto a total (a formula cell) | "F2: 1,250.00, formula =D2*E2" (the formula comes from the app's edit info) |
| 4 | ⇧↓ twice | "…, selected F2 to F4 (3 rows, 1 columns)" |
| 5 | ⌘-click another cell | "…, plus 1 more range" |
| 6 | Type `12`, Enter | After the commit the next cell is announced; moving back onto the edited cell reads "12" (the value changed, so the mirror re-announces it) |
| 7 | F2 | VO announces "Cell editor, edit text" with the cell's input; Esc returns to the cell |
| 8 | ⌘F2 | "Function Wizard, dialog"; focus is in Search; VO+Right reads Category, Search, the Functions list ("listbox, N items"), the signature and description, Cancel, Insert |
| 9 | Tab ×8 inside the dialog | Focus cycles Category → Search → list → Cancel → Insert → Category (never leaves the dialog); Shift+Tab from Category lands on Insert |
| 10 | Type `sumif`, Enter | The dialog closes and the cell editor reads "=SUMIF(" (W5-6 adds the argument fields; Esc cancels the edit) |
| 11 | ⌘F3 (Define name), Esc | "Define name, dialog" … Esc returns focus to the grid cell, which is announced again |
| 12 | Insert ▸ Chart… (after W5-5) | The chart is a group item "Sales, image"; Delete removes it, arrows nudge it |
| 13 | VO+U (rotor) › Landmarks | The grid, the toolbar, the formula bar and the status bar are listed; the sheet tabs are a tablist |

### Dialogs and chrome checklist (1.0)

With VoiceOver on, and with System Settings › Keyboard › "Keyboard navigation" both on and off:

- [ ] ⌘1 (Format Cells): VO says "Format Cells, dialog"; Tab reaches every control in order, the tabs read "tab, 1 of N, selected"; ←/→ switch tabs; Escape closes and VO is back on the cell.
- [ ] Format Cells › Font: the Font name box reads "Font name, combo box"; ↓ reads the font names with "N of M"; Typeface and Size read as list boxes and ↑/↓ change them.
- [ ] ⌘, (Options): every checkbox and select has a spoken label; Enter = OK, Escape = Cancel.
- [ ] File › Page Setup…: radio groups (Orientation, Scale) read "radio button, 1 of 2" and ←/→ change them; "Paper" reads its label.
- [ ] Data › Sort…, Data › More Filters › Standard Filter…: Tab cycles inside; Escape returns to the cell.
- [ ] Toolbar: Tab to "Sort", Enter opens the menu ("menu, 3 items"), ↓/↑ move, Enter on "Sort…" opens the dialog; Escape there lands back on the "Sort" button.
- [ ] Narrow the window until "»" appears: Tab to it ("More buttons, collapsed"), Enter expands it and moves into the panel ("toolbar"); Escape returns to "»".
- [ ] The toolbar's font name and size boxes read as combo boxes; ↓ opens the list; Enter applies; Escape leaves.
- [ ] Sheet tabs: one Tab stop; ←/→ switch sheets and VO reads "Sheet2, tab, selected".
- [ ] Sidebar › Editing: reads "Open documents, tab list"; ↑/↓ move, Enter shows, ⇧F10 opens Close / Close Others.
- [ ] File › Print Preview: "Print Preview, dialog", focus on Close; Tab stays in the preview; Page Setup… from there and Escape closes only Page Setup.
- [ ] ⌘/ (Keyboard shortcuts) and Help › About: Escape closes them.
- [ ] Every focused control shows a visible focus ring (also in dark mode).

Deviations to note in `docs/parity-deviations.md`: VoiceOver's table navigation
(VO+arrows reading row/column headers) is not available on the canvas; the live region
covers position and content instead. Windows Narrator / NVDA: the same tree applies
(`aria-activedescendant` on the focused textarea), to be checked on a Windows machine.
