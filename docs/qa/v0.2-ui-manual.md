# v0.2 UI: manual check script

Run `pnpm --filter tally-desktop dev:web`, open `http://localhost:5173/?template=invoices` (MockClient), and repeat the starred steps in `pnpm tauri dev` against the engine. The automated flows are in `tests/e2e/v02.spec.ts`.

| # | Step | Expected |
|---|---|---|
| 1 | Type `=SU` in H2 | Autocomplete lists SUM (engine: SUM, SUMIF, SUMPRODUCT…); ↑/↓ move; Tab or Enter inserts `SUM(`; Esc hides it |
| 2 | Inside `SUM(` | Signature tooltip; the current argument is bold and accent-coloured |
| 3 | `=` then click D2, type `*`, press ↓ ↓ | `=D2*E3` style references appear at the caret; each reference has its own colour in the editor, the formula bar and as a grid outline; ⇧+click / ⇧+arrow extends the range |
| 4 | Edit from the formula bar, click cells | Same point mode; focus stays in the bar |
| 5 | ⌘Z while editing | Undoes typing in the editor only (document undo untouched) |
| 6 | Type 1, 2 in A20:A21, drag the fill handle to A25 | 3, 4, 5, 6; `Monday` → weekdays; `Item 1` → Item 2…; a formula re-anchors (engine) ★ |
| 7 | Double-click the fill handle next to a filled column | Fills down to the end of the neighbour's data ★ |
| 8 | ⌘-click several cells / ranges | All ranges tinted; status bar Sum/Count cover all; Bold applies to all |
| 9 | Drag a row-header boundary; double-click a column-header boundary | Row height changes (one undo step); the column fits its widest text ★ |
| 10 | Format bar: U, S, size 14, font/fill colour (swatch and custom hex), align, wrap, number formats, Custom… | Toggles reflect the active cell; Custom… previews the code live |
| 11 | Select G2:G15, "Colour by value" | Paid green, Due amber, Overdue red chips (one undo step) |
| 12 | Right-click a row header / column header / cell | Insert above/below/left/right, Delete, Hide / Show, Freeze rows (rows) or Sort (columns), Resize…, Clear; cell menu Cut/Copy/Paste/Paste values/Paste special, Sort, AutoFilter, Merge, Define name ★ |
| 13 | ⇧⌘V after copying a formula | Pastes the displayed values, not formulas ★ |
| 14 | Moon button / palette "Theme" | system → light → dark, persisted across reloads; grid, chips and fills legible in dark |
| 15 | ⇧⌘G | "At a glance": Rows 14, Sum of Total $686.10, Status counts, Total by Status bars; updates after edits (300 ms) |
| 16 | ⌘/ | Shortcut reference |
| 17 | Share → Export ODS… | Save dialog with ODS ★; the file appears under "Open recent" with a relative time ★ |
