# v0.3 UI: manual check script

Run `pnpm --filter tally-desktop dev:web` and open `http://localhost:5173/?template=invoices`
(WebMockClient), then repeat the starred steps in `pnpm tauri dev` against the engine.
Automated: `tests/e2e/v03.spec.ts` (browser flows; the mock records ops in
`window.__tally.client.recorded` and `setLocale` / `openUrl` / `goalSeek` calls in
`recordedCalls`), `packages/app/test/v03*.test.ts`, `packages/grid/test/v03.test.ts`,
and `apps/desktop/src-tauri/src/tests.rs` (real engine: CF style in `cells()`, validation
Stop, note ODS round trip, protection, goal seek, `open_url`, argument limits).
Screenshots: `docs/qa/screenshots/v03-*.png`, regenerated with
`pnpm --filter tally-desktop exec playwright test -c ../../tests/e2e/screenshots.config.ts`.
★ = repeat against the engine (the mock evaluates a subset of rules, does not reformat for
locales and computes goal seek proportionally).

## Conditional formatting

| # | Step | Expected |
|---|---|---|
| 1 | Select F2:F15, format bar **Highlight ▾ ▸ Greater than…**, type 60, Apply | Cells above 60 get a light red fill and dark red text; one ⌘Z removes the rule ★ |
| 2 | **Highlight ▾ ▸ Colour scale**, then **Data bars**, then **Icon set (arrows)** on F2:F15 | Red → yellow → green fill, a gradient bar behind each value (starting right of the icon) and green ↑ / amber → / red ↓ arrows (`v03-total-cf.png`) ★ |
| 3 | **Highlight ▾ ▸ Manage rules…** (or Format ▸ Conditional Formatting…) | Manager lists every rule, highest priority first, with a preview, its summary and range (`v03-cf-manager.png`); ▲▼ reorder (within a format, or moves the whole format); Edit; Delete |
| 4 | New rule… | Editor: Apply to (selection), Rule type (cell value, formula, colour scale 2/3 stops, data bar, icon set, top/bottom, average, duplicate/unique, text, blank, errors, date is), the type's fields, style presets, B/I/U/S, text/fill colour, "Show as a chip" with chip colours, preview, Stop if true (`v03-cf-editor.png`) |
| 5 | Formula rule `$G2="Overdue"` on A2:G15 | Whole rows of overdue invoices highlighted ★ (the mock does not evaluate formula rules) |
| 6 | Select G2:G15, **Colour by value** twice | Paid / Due / Overdue chips; the second run updates the same rule (one format in the manager, not two); editing a status to "Paid" recolours it |
| 7 | Change F3 to 200 | The colour scale, bar and icon of the whole column update ★ |
