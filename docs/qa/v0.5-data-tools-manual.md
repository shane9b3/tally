# v0.5 manual QA: data tools, dialogs, panels, options, assists, i18n (W5-6)

Run against the desktop app (`pnpm tauri dev`) with the engine's W5-2/W5-3
work in place; the browser build (`pnpm dev:web`) emulates every op in
`WebMockClient`, so the dialog flows can be checked there too. Automated
coverage: `tests/e2e/{data-tools,options,i18n}.spec.ts`, the `w56*.test.ts`
vitest files and `apps/desktop/src-tauri/src/{prefs,autosave,templates,l10n}.rs`
unit tests. Screenshots: `docs/qa/screenshots/v05-*.png`
(`pnpm --filter tally-desktop exec playwright test -c ../../tests/e2e/screenshots.v05.config.ts`).

## A. DataPilot

1. Invoice template, click B3, Data ▸ DataPilot ▸ Start…. Expect the layout
   dialog with the field list (Date, Customer, Description, Qty, Price,
   Total, Status) and four empty areas.
2. Drag Customer into Row fields, Status into Column fields and Total into
   Data fields (or use the R / C / Σ buttons). Click the data chip: the
   function picker shows the 11 functions; the caption reads "Sum - Total".
3. Click a row-field chip: Field Options show subtotals, sort, layout,
   show-empty, AutoShow and the item list (hide an item).
4. More ▸ Results to: Sheet1, target J2, OK. Expect the output at J2 with
   bold header rows and a tinted header band, "Total Result" at the end.
5. Put the cursor inside the output: the context menu offers Refresh, Layout…
   and Delete pivot table; Data ▸ DataPilot ▸ Refresh is enabled.
6. Change a Total value in the source, Refresh: the output updates.
7. Double-click a data cell: a new sheet with the matching source rows.
8. Create again at a non-empty target: "The target range is not empty.
   Overwrite it?" — Yes overwrites.
9. ⌘Z after each step restores the previous state (one undo step per action).

## B. Data tools

- **Standard filter** (Data ▸ Filter ▸ Standard Filter…): Total > 60 OR
  Status = Overdue hides the other rows; Regular expressions and No
  duplications toggle; Copy results to H1 writes the matches instead; Reset
  Filter shows every row.
- **Advanced filter**: criteria block (labels + two rows) picked with ⌖.
- **Subtotals**: group by Status, calculate Total with Average; rows
  "<Status> Average" with SUBTOTAL(1;…) appear and the outline gutter shows
  the groups; Remove all deletes them.
- **Consolidate**: add two ranges (Sheet1.F2:F8, Sheet1.F9:F15), destination
  Sheet2.A1, Sum, By row labels.
- **Text to columns**: type `north;7;x` in A21, Data ▸ Text to Columns…; the
  preview grid updates as separators are toggled; OK splits into A21:C21.
- **Remove duplicates**: compare on Customer only.
- **Group / outline**: select rows 3–5, F12; the gutter shows a +/− box;
  clicking it hides the rows; level buttons; ⌘F12 ungroups; AutoOutline;
  Data ▸ Group and Outline ▸ Show Level… / Remove Outline.
- **Scenarios** (Tools ▸ Scenarios…): create "High" from F2:F3, change
  values, create "Low", Show "High" restores (copy back on); Navigator lists
  them with Show.
- **Define database range**, **Create names from labels** (top row → names
  Date, Customer, …), **Fill series** (linear 10 step 5, preview line).
- **Sort with options** (Data ▸ Sort with Options…): left to right, custom
  list (Mon…Sun), copy results to.
- **Delete**: the Delete key opens Delete Contents (Numbers only keeps text);
  Backspace clears immediately; Tools ▸ Options ▸ Input can turn the dialog off.
- **Multiple operations**: A4:A8 variable values, formula B4, column input
  B1: MULTIPLE.OPERATIONS formulas in B4:B8.
- **Insert / Delete Cells** (⌃⌘+ / ⌃⌘−, context menu): shift down / right,
  up / left, entire rows / columns.
- **Sheet tabs**: right-click → Copy sheet… (name, position), Tab colour…,
  Hide sheet (the last visible one refuses), Show sheet… lists hidden tabs.
- **Merge** with hidden content: "Should the contents of the hidden cells be
  moved into the first cell?" Yes moves the text (one line each), No keeps
  only the first cell, Cancel does nothing.

## C. Styles, AutoFormat, Format Cells

- ⌘F11 opens the Styles panel: Default, Heading, Heading 1, Result, Result 2
  (plus custom). Click applies; New style… from the selection; Edit; Delete
  (custom only); the paint can applies the selected style to clicked cells
  until Esc.
- Format ▸ AutoFormat… over a table: the 17 presets with previews; options
  checkboxes change the preview and what the engine applies.
- ⌘1 Format Cells: Numbers (codes + preview), Font, Font Effects (underline
  styles incl. double), Alignment (rotation −90…90, indent, shrink to fit,
  stacked), Borders (outer/all/none presets, every edge incl. the diagonals,
  line style/width/colour), Background, Cell Protection.

### C2. Font pickers (toolbar font box, size box, Format Cells ▸ Font)

Desktop app (lists the fonts installed on this Mac); the browser build lists
a fixed set (Arial, Courier New, Georgia, Helvetica, Inter, Tahoma, Times New
Roman, Trebuchet MS, Verdana).

- The format strip starts with the font-name box and the size box. On a cell
  without a font of its own the box shows the document's font (Arial in an
  Excel file, Inter in a new sheet). Select cells in two different fonts:
  the box is blank; same for two sizes.
- Click the chevron: "Recently used", "Fonts in this document", "All fonts",
  each name drawn in its own face. Scroll a list of several hundred families:
  no lag. Type "hel": the list narrows, Helvetica is highlighted; ↑ ↓ move,
  Enter applies to the whole selection (one undo step: ⌘Z restores), Esc
  closes the list, a second Esc returns to the grid unchanged.
- Type a name that is not installed ("Foo Sans") and press Enter: applied;
  the cells draw with the fallback font; print/PDF uses a substitute too.
- Pick the document's own font: the cells lose their own family (save to
  ODS: no `style:font-name` on those cells' styles).
- The picked font is at the top of "Recently used" in other documents and
  after a restart.
- Size box: type 10.5 and Enter (row heights and AutoFit follow); 0 or 500
  shows an error and keeps the size.
- ⌘1 ▸ Font: search field + list, Typeface list (Regular, Italic, Bold, Bold
  Italic; faces the family lacks say "synthesised"; families with Light /
  Medium / Condensed faces show the note that only four typefaces are
  stored), size field + list (6–96), preview of the active cell's text in the
  chosen font, typeface, size and colour. A name that is not installed shows
  "This font is not installed; a substitute will be used." Install a font
  while Tally runs, click "Rescan installed fonts": it appears.
- ⌘1 on a mixed selection: font, typeface and size are blank; OK without
  touching them leaves each cell's font as it was; picking one sets all.
- Switch the UI language (Tools ▸ Options): all of the above is translated.

### C3. Toolbars: show / hide bars and buttons (AOO View ▸ Toolbars)

- View ▸ Toolbars: Toolbar, Formatting Bar, Formula Bar, Status Bar toggle
  the bars (also in ⌘K). With the Toolbar hidden a thin strip keeps the
  document title; on macOS it is tall enough for the traffic lights, the
  window still drags by it (with the sidebar open and closed), and the grid
  never slides under the traffic lights.
- Right-click the Toolbar or the Formatting bar: Visible Buttons ▸ lists
  every button with a check; unchecking hides it at once, separators next to
  hidden buttons disappear (hide Undo and Redo: one rule between Save and
  Sort). The flyout opens to the left near the window's right edge.
- View ▸ Toolbars ▸ Customize Toolbars…: the bars and both toolbars'
  buttons as checkboxes; Reset to Default shows everything again.
- Hidden buttons keep working from the menus, their shortcuts (⌘B with
  Bold hidden) and ⌘K.
- The choice survives a restart and reaches every open window and tab at
  once (two windows side by side).
- Make the window narrow: buttons that do not fit move into "»" at the end
  of the bar (nothing is clipped); "»" opens them in a panel and they work
  from there (colour pickers, Highlight menu, font boxes). Widening the
  window brings them back.

## D. Options, assists, panels

- ⌘, Options: Calculate (iterations, steps, min change, date epoch, case,
  precision as shown, whole cell, criteria mode, text-to-number) → changes
  persist in the document; View toggles; Input (AutoInput, AutoCorrect rules,
  Enter direction, Delete key); Formula syntax; Sort lists editor; Load/Save
  (default format, autosave minutes); Language (UI language, default locale).
  Prefs persist after a restart (`prefs.json` in the app config dir).
- AutoInput: type "Ac" under a column with "Acme Ltd": ghost text "me Ltd";
  Enter accepts; → or End accepts without committing; Esc dismisses; ⌃D
  shows the selection list of the column.
- AutoCorrect: "teh TEst" → "The Test"; "1st" stays; "a - b" → "a – b";
  ⌘Z reverts the whole entry.
- Function Wizard (⌘F2): one field per parameter with a ⌖ pick button; the
  formula line shows the call; Insert writes it; re-opening on a cell with a
  call fills the fields.
- Navigator (F5): sheets, names, database ranges, charts, pictures, pivots,
  notes, scenarios; double-click jumps; Show on a scenario; Layout on a pivot.
- Tools ▸ Document Statistics…: sheets, cells, formulas, charts, notes, names.
- Autosave: set 1 minute, edit, wait; `<app data>/autosave/doc-<id>-<name>.ods`
  appears with a `.json` sidecar. Force-quit, relaunch: the Recover dialog
  lists it; Recover opens it as Untitled (dirty); Discard deletes it. A real
  Save removes the snapshot.
- Save as Template (⇧F11): `<app data>/templates/<name>.ots` with the
  template mimetype; the sidebar lists it under Templates; opening it gives an
  untitled workbook.

## E. i18n and shortcuts

- Options ▸ Language ▸ Deutsch: the native menu rebuilds (Datei, Bearbeiten,
  Ansicht…), the toolbar reads Rückgängig / Wiederholen, the palette groups
  read Datei / Bearbeiten, dialogs use the German labels. Français / Español
  likewise. English restores everything.
- View ▸ Locale ▸ Deutsch: the formula bar shows `=SUMME(F2:F3)` for a SUM
  formula; typing `=SUMME(...)` commits the canonical `=SUM(...)` (display-level
  localisation; files keep English names).
- Every binding in `docs/shortcuts.md` works; `keymap.test.ts` keeps the table
  and the document in sync.

## Known limits (see the W5-6 report)

- Outline groups and view options have no read query yet (`outline()` /
  `SheetLayout.rowGroups`, `viewOptions()`): the UI mirrors its own ops, so
  groups created by another client (or read from a file) do not show in the
  gutter until the engine exposes them.
- Show formulas / value highlighting / zero values / grid lines / headers are
  applied as `setViewOptions` ops; the grid renders them once W5-5 adds the props.
- Solver needs the W5-3 engine; the dialog reports its `unsupported` error until then.
- AutoFormat previews are approximations; the engine owns the real formats.
